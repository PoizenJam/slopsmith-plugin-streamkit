OBS scene automation

Switches OBS scenes from the live state via obs-websocket v5. Add a dedicated Browser Source or Custom Browser Dock (not inside a scene it switches) pointing at:

[host]/api/plugins/stream_kit/assets/scene-control/index.html

Scene for each state (leave blank to ignore):

Menus / library
Stopped / idle
Song loaded
Playing
Paused
Results

The controller reads this config (incl. the obs-websocket password) over the local API — intended for a single-machine setup. Scene names must match OBS exactly.
